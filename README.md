# Weather Rundown

Ask Siri "What's the weather?" and you only get current conditions. This Siri Shortcut gives you the whole day. Say **"Hey Siri, Weather Rundown"** and you'll hear something like:

> Right now it's 58°F and Cloudy. Today: Rain, with a high of 64°F and a low of 51°F. Chance of rain: 80%. Bring an umbrella.

It uses Apple's weather data for wherever you are. You can run it from your iPhone, iPad, Mac, Apple Watch, HomePod, or CarPlay.

## Get the shortcut

Pick one. Whichever you choose, iCloud copies it to your other devices.

| If you have… | Do this | Takes |
|---|---|---|
| A Mac | [A. Import the pre-built shortcut](#a-import-the-pre-built-shortcut-mac) | 2 min |
| An iPhone or iPad | [B. Build it yourself](#b-build-it-yourself-iphone-or-ipad) | 10 min |
| iOS 27 with Apple Intelligence | [C. Describe it to Shortcuts](#c-describe-it-to-shortcuts-ios-27) | 2 min |

### A. Import the pre-built shortcut (Mac)

Apple only imports signed shortcut files, and Apple's signing tool runs on a Mac.

1. On GitHub, click **Code → Download ZIP**, then unzip the download.
2. Open **Terminal**, type `cd ` (with a space), drag the unzipped folder into the window, and press Return. Then run:
   ```sh
   sh shortcut/sign-on-mac.sh
   ```
3. Shortcuts opens the signed file. Click **Add Shortcut**.

The pre-built shortcut already has **Show on Apple Watch** turned on.

> **Note:** The file is generated by `shortcut/build_shortcut.py` and checked by automated tests, but it hasn't been imported on a real Apple device yet. If Shortcuts won't open it, use option B.

### B. Build it yourself (iPhone or iPad)

Open **Shortcuts** and tap **+**. On iOS 27 with Apple Intelligence, **+** opens *Describe a Shortcut*: skip it to build by hand, or use [option C](#c-describe-it-to-shortcuts-ios-27). Tap the name at the top, choose **Rename**, and type `Weather Rundown`.

To add each action below, type its name in the search bar at the bottom and tap it. New actions land at the bottom of the shortcut. To move one, press and hold it, then drag.

**Today's forecast**

1. **Get Weather Forecast**: leave it on *Daily* and *Current Location*.
2. **Get Item from List**: leave it on *First Item*. That's today.
3. **Set Variable**: tap *Variable Name* and type `Today`.

**Chance of rain.** Shortcuts sometimes reports a 40% chance as 0.4. These steps turn either form into a whole percent.

4. **Get Details of Weather Conditions**: tap *Detail* and choose **Precipitation Chance**. Its input should say *Today* (or *Item from List*, which is the same thing).
5. **If**: it should say *Precipitation Chance*. Set the condition to **is less than or equal to** and the number to `1`.
6. **Calculate**: drag it between *If* and *Otherwise*. Make it *Precipitation Chance* **×** `100`. If the first box shows something else, tap it, choose **Select Variable**, and tap *Precipitation Chance*.
7. **Calculate**: drag it between *Otherwise* and *End If*. Make it *Precipitation Chance* **×** `1`.
8. **Round Number**: leave it below *End If*. It should say *If Result*.

**Umbrella reminder**

9. **If**: it should say *Rounded Number*. Set **is greater than or equal to** `50`.
10. **Text**: drag it between *If* and *Otherwise*, then type `Bring an umbrella.`
11. **Nothing**: drag it between *Otherwise* and *End If*.

**Right now**

12. **Get Current Weather**: leave it on *Current Location*.
13. **Set Variable**: name it `Now`.

**The message**

14. **Text**: type the message below. Wherever there are brackets, insert a variable: tap a suggestion above the keyboard, or tap **Select Variable**. Then tap the variable you inserted and choose the detail named after the ›.

    > Right now it's [Now › Temperature] and [Now › Condition]. Today: [Today › Condition], with a high of [Today › High] and a low of [Today › Low]. Chance of rain: [Rounded Number]%. [If Result]

    For the last one, use the *If Result* from the umbrella step, which is the second If.
15. **Show Content**: it should say *Text*. Before iOS 26, this action was called **Show Result**.

Tap ▶ to test it. When it asks for your location, choose **Always Allow** so Siri can run it hands-free.

> **Want it shorter?** Skip steps 4–11, and end the message after "…a low of [Today › Low]."

### C. Describe it to Shortcuts (iOS 27)

On iOS 27 with Apple Intelligence turned on, Shortcuts can build a shortcut from a description. Tap **+**, choose **Describe a Shortcut**, and paste:

> Make a shortcut named "Weather Rundown". Get the daily weather forecast for my current location and use the first day as today. Also get the current weather for my current location. Show this so Siri reads it aloud: "Right now it's [current temperature] and [current condition]. Today: [today's condition], with a high of [today's high] and a low of [today's low]. Chance of rain: [today's precipitation chance as a whole number]%." If the chance of rain is 50% or more, add "Bring an umbrella." The precipitation chance may come back as a fraction like 0.4; if it's 1 or less, multiply it by 100.

AI-built shortcuts vary, so compare what you get with option B and test it.

## Put it on all your devices

**First, turn on iCloud Sync on every device.** Each device must be signed in to the same Apple Account.

- **iPhone and iPad:** Settings → Apps → Shortcuts → **iCloud Sync**. On iOS 17 and earlier, it's Settings → Shortcuts.
- **Mac:** In the Shortcuts app, open Settings and turn on **iCloud Sync**.

Then, on each device:

- **iPhone and iPad:** Say "Hey Siri, Weather Rundown". This works through AirPods too.
- **Mac:** Allow location access in System Settings → Privacy & Security → Location Services → **Shortcuts**. Then ask Siri, or run the shortcut from the Shortcuts app.
- **Apple Watch:** On your iPhone, open the shortcut, tap **ⓘ**, and turn on **Show on Apple Watch**. The pre-built file already has this on. Then raise your wrist and say "Weather Rundown". It's not confirmed that every watchOS version can run the weather actions on the watch itself. If yours says an action isn't supported, ask your iPhone, AirPods, or HomePod instead.
- **HomePod:** HomePod runs your shortcuts through your iPhone. In the Home app, tap **⋯ → Home Settings**, tap your name, and turn on **Recognize My Voice** and **Personal Requests**. Your iPhone needs to be at home on the same Wi-Fi.
- **CarPlay:** Just ask Siri.

When you ask Siri, it reads the result aloud. When you tap the shortcut instead, the text shows on screen. To have it read aloud then as well, replace **Show Content** with **Speak Text**.

## Make it yours

- **Pick your own phrase.** The shortcut's name is what you say to Siri, so rename it to whatever you'd naturally say. Apple says that when a shortcut has the same name as a built-in Siri request, Siri runs the shortcut instead. Naming it `What's the weather` should therefore replace Siri's usual answer. If Siri keeps giving its normal answer, go back to a more distinctive name.
- **Umbrella threshold.** Change the `50` in step 9. In the pre-built shortcut, it's in the second *If*.
- **A fixed city.** Tap *Current Location* in both weather actions and pick a place.
- **More details.** In the message, tap a *Now* or *Today* variable to choose another detail. Options include Feels Like, Humidity, UV Index, Wind Speed, Sunrise Time, Sunset Time, and Air Quality Category. Some details, such as Pressure, only exist for current weather. Humidity can have the same 0.4-instead-of-40% quirk as the rain chance.
- **Tomorrow too.** Add **Get Item from List** and set it to *Item At Index* `2`. Tap its input, choose **Select Variable**, and tap the output of *Get Weather Forecast*. Add **Set Variable** `Tomorrow`, and drag both actions above the message. Then add this to the end of the message: `Tomorrow: [Tomorrow › Condition], with a high of [Tomorrow › High] and a low of [Tomorrow › Low].` To get this in the pre-built file, run `python3 shortcut/build_shortcut.py --tomorrow` before signing.

## Troubleshooting

- **Siri gives its usual weather answer.** Siri matched a built-in request instead of your shortcut. Say "Run Weather Rundown", or rename the shortcut to something more distinctive.
- **"Couldn't get current location", or Siri can't run it.** Run it once by tapping it and allow location access. Then check that Settings → Privacy & Security → Location Services → **Shortcuts** is allowed.
- **The rain chance sounds wrong**, like "0.4%" or "4000%". Check that step 5 compares with `1` and step 6 multiplies by `100`.
- **It's not on my other devices.** Turn on iCloud Sync on each device, check they all use the same Apple Account, and give it a few minutes.
- **HomePod says it can't reach your shortcuts.** Turn on Personal Requests (see above) and make sure your iPhone is on the home Wi-Fi. In the Find My app, open **Me** and turn on **Use This iPhone as My Location**.

## How the pre-built file is made

`shortcut/build_shortcut.py` writes `shortcut/weather-rundown.unsigned.shortcut`, an XML property list in Apple's Shortcuts format. It uses only Python's standard library. `shortcut/sign-on-mac.sh` signs the file with Apple's `shortcuts sign` command and opens it.

```sh
python3 shortcut/build_shortcut.py                   # rebuild the file
python3 shortcut/build_shortcut.py --tomorrow        # add tomorrow's outlook
python3 shortcut/build_shortcut.py --umbrella-at 40  # umbrella reminder from 40%
python3 -m unittest discover -s tests -v             # run the tests
```

The pre-built file spells out each weather detail as its own *Get Details* step rather than using *Now* and *Today* variables. The result is the same.

The tests run the generated shortcut through a small simulator (`tests/simulate.py`) with made-up weather. They check exactly what Siri would say, including both ways Shortcuts reports the rain chance.
